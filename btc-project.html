Core Bot Functionality

Key features built into the automated Python monitoring engine

Asynchronous Execution

Real-Time Price Tracking

Continuously polls the Binance REST API or WebSocket feed to monitor BTC spot prices with sub-second latency and minimal memory footprint.

Threshold Breach Alerts

Triggers instantaneous Telegram messages whenever prices drop below predefined floor limits or break above upper ceiling targets.

Big Movement Detection

Analyzes candle velocity to identify rapid price percentage spikes or sudden market dumps within short timeframe windows.

Hourly Volatility Audits

Calculates rolling volatility standard deviations on an hourly cadence to keep traders informed during high market turbulence.

CSV Data Logging

Automatically logs timestamped price updates to local CSV files for persistent record-keeping and backtesting analysis.

Dashboard Chart Generation

Generates high-resolution graphical trend charts using Matplotlib to summarize intraday trends directly inside Telegram reports.
