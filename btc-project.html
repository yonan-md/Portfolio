BTC Live Monitor Bot

This project monitors live BTC prices using Python and Binance API. It sends Telegram alerts when price crosses thresholds, detects big moves, and logs all price data. A dashboard chart visualizes price trends over time.

Features

  • Real-time BTC price tracking
  • Low & High threshold alerts
  • Big price movement detection
  • Hourly volatility monitoring
  • CSV logging and chart visualization
